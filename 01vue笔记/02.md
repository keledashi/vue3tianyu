# ■ vue的特点
## □ 渐进式框架
- 根据实际需求，`逐步引入`使用
- 简单场景：在普通的HTML页面中，引入vue，直接使用
- 复杂场景：使用构建工具，结合vue-router、pinia等生态工具完成开发
## □ 声明式编码
- 只描述页面应该是什么样的，无需手动频繁操作DOM
    ```html
    <ul>
        <li v-for="p in arr" :key="p.id" >
            {{p.name}} - {{p.age}}岁
        </li>
    </ul>
    <script setup>
        const arr = [
            {id:'a001',name:'zhangsan',age:18},
            {id:'a002',name:'lisi',age:19},
            {id:'a003',name:'wangwu',age:20}
        ]
    </script>
    ```
- 对应的是`命令式`编码：需要操作DOM
    ```html
    <ul id='list'></ul>
    <script>
        const arr = [
            {id:'a001',name:'zhangsan',age:18},
            {id:'a002',name:'lisi',age:19},
            {id:'a003',name:'wangwu',age:20}
        ]
        const list = document.getElementById('list')
        for(let i = 0 ; i < arr.length; i++){
            const li = document.createElement('li')
            li.innerText = `${arr[i].name} - ${arr[i].age}岁`
            list.appendChild(li) 
        }
    </script>
    ```

## □ 响应式数据
- 数据变化后，Vue会自动更新页面上的相关内容，实现`数据驱动视图`
    ```html
    <ul>
        <li v-for="p in arr" :key="p.id" >
            {{p.name}} - {{p.age}}岁
        </li>
    </ul>
    <script setup>
        import {ref} from 'vue'
        /* 
          交给ref，那么arr数组就变成响应式的数据，
          数组数据变动，页面内容也变化。
        */
        const arr = ref([
            {id:'a001',name:'zhangsan',age:18},
            {id:'a002',name:'lisi',age:19},
            {id:'a003',name:'wangwu',age:20}
        ])
    </script>
    ```
