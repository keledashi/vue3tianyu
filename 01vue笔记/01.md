# ■ 新旧对比
## □ API
### 选项式API
```html
<script>
    export default{
        // 组件名
        name:'Zizujian',
        // 数据
        data(){
            return {
                name:'zhangsan'
            }
        },
        // 方法
        methods:{
            changeName(){
                this.name = 'lisi'
            }
        }
    }
</script>
```
### 组合式API
```html
<script setup lang='ts'>
    // 引入ref来定义响应式数据
    import {ref} from 'vue'
    // 使用defineOptions宏函数定义组件的配置
    defineOptions('name','Zizujian')
    // 数据
    let name = ref('zhangsan')
    // 方法
    function changeName(){
        name.value='lisi'
    }
</script>
```

## □ v-model应用于组件标签
### vue3.4之前
```javascript
// 接收父组件传递的 modelValue 数据
const props = defineProps(['modelValue'])
// 声明组件向外触发的的更新事件
const emit = defineEmits(['update:modelValue'])
// 修改数据时，通过事件通知父组件更新
emit('update:modelValue',value)
```
### vue3.4+
```javascript
// 直接声明一个可双向绑定的model
const model = defineModel()
```
